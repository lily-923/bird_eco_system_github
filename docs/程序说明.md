# 程序说明（数字图像处理综合实践）

## 一、任务定位（按课程要求修正后）

**本程序不做物种预测，也不使用任何深度学习/大模型。**

工作方式是：
1. 选择一张鸟类图片时，其类别是**已知**的（CUB-200-2011 的物种文件夹 / 标注文件给出类别；
   外部图片由用户在界面中手动指定已知类别）；
2. 对该图片执行**传统数字图像处理与分割**（OpenCV + numpy 基础算子）；
3. 在分割结果上计算一系列**图像指标**；
4. 取该物种在数据集中**全部图片**的指标均值/标准差作为**物种基线**，
   计算：差额 = 当前图片指标 − 物种均值；z分数 = 差额 / 物种标准差；
5. 给出 AVONET 中该物种的形态与生态指标作为**参考与解释**（体重、喙/翅/尾、
   栖息地、营养级、食性、生活方式、迁徙、分布范围）。

## 二、处理流程（链式叠加）

```
原图
 ├─ 双边滤波去噪 + CLAHE 亮度增强            → 增强图
 ├─ 按标注框裁剪 + 外扩 6%                   → 裁剪图
 ├─ 背景色距离图 + Otsu + 形态学 + 最大连通域 + GrabCut 精细细化 → 前景蒙版
 └─ 图像指标（126 维特征）:
      颜色 HSV 直方图(34) / 形貌(12) / GLCM(7) / 均匀LBP(59)
      / 分形维数(2) / 对称性(4) / 灰度统计(2)
```

## 三、图像指标与差额定义

展示指标（可解释性强、与图案/表型相关）：
图案复杂度(分形维数)、左右对称度、上下对称度、纹理对比度、纹理熵、纹理同质性、
前景面积占比、形状紧致度、边缘密度、形状长宽比、灰度标准差。

- **差额 = 当前图片指标 − 该物种全部图片的均值**
- **z分数 = 差额 / 该物种标准差**
- 评价：|z|≤1 在典型范围内；1<|z|≤2 略高/略低；|z|>2 明显偏高/偏低

## 四、模块结构

| 文件 | 作用 |
|---|---|
| src/data_io/cub_dataset.py | 读取 5 个标注文件并合并；全量校验（200类/11788张/5994-5794），不通过则报错 |
| src/data_io/avonet.py | CUB↔AVONET 映射（自动匹配+人工校正，200/200 命中），生成性状表 |
| src/preprocessing/image_ops.py | 去噪、CLAHE、bbox 裁剪、Otsu+形态学分割、蒙版叠加 |
| src/features/descriptors.py | 126 维手工特征（GLCM/LBP/形貌/颜色/分形/对称性） |
| src/features/visualize.py | 生成 10 张分步处理与特征可视化图 |
| src/analysis/compare.py | 物种指标基线 + 个体差额/z分数 + AVONET 参考指标 |
| src/models/feature_db.py | 全量特征库构建（多进程 + 缓存） |
| src/models/analysis.py | 数据集统计图 + PCA 无监督聚类图 |
| src/gui/app.py | Tkinter 界面（三个页签） |
| scripts/01~05 | 一键脚本：映射 / 特征库 / 基线 / 界面 / 自检 |

## 五、图形界面

1. **浏览 / 检索 / 统计**：检索 200 种鸟、查看样本与 AVONET 生态性状、数据集统计；
2. **单张指标分析（已知类别）**：选图 → 自动确定类别（外部图片手动选择）→
   显示图像指标 vs 物种基线的差额表（当前值、均值、标准差、差额、z分数、评价）
   + AVONET 参考指标；
3. **分步处理与特征可视化**：10 张步骤图（原图/增强/裁剪/分割/灰度+边缘/
   GLCM热力图/LBP图/对称轴/分形log-log/颜色直方图），缩略图切换，右侧显示算法说明与数值。

## 六、运行步骤

```
python scripts/01_build_traits.py      # CUB↔AVONET 映射表
python scripts/02_extract_full.py      # 全量特征库（11788 × 126）
python scripts/03_build_baseline.py    # 200 个物种的指标基线
python scripts/04_run_gui.py           # 启动界面
```

## 七、与课程要求对应

- 数据集不删减：启动即校验 200 类 / 11788 张 / 官方划分 5994-5794；
- 不使用深度学习：分割与特征全部为 OpenCV/numpy 基础算子；无预测模型；
- 传统/自适应分割：Otsu 自动阈值 + 形态学 + 连通域 + GrabCut 细化；
- 特征提取：形貌/纹理/颜色/对称性/分形复杂度；
- 生态指标映射与解释：AVONET（200/200 命中）；
- 图形界面：浏览检索、单张指标分析、分步可视化；
- 可复现：随机种子固定 seed=42。



## 九、应用场景与软件形态（鸟类表型—生态性状分析系统）

- 软件名称：鸟类表型—生态性状分析系统；
- 应用场景：鸟类生态学/表型研究 + 保护区鸟类监测数据质控；
- 用户：科研人员、研究生、保护区监测人员、课程教学；
- 软件形态：桌面分析工具（Tkinter 应用外壳：主页、菜单栏、状态栏、关于/帮助、
  应用图标、无控制台启动方式、可打包为 exe）；
- 核心价值：把“体表图案测量”与“AVONET 生态性状”放在同一分析链条里，
  用差额与 z 分数客观描述个体相对物种典型表型的偏离。

## 十、批量批次分析与报告

- 批量页签：选择批次文件夹，两种已知类别模式
  （按子文件夹自动识别 / 整批统一指定物种）；
- 处理过程：逐张执行与单张分析相同的传统处理与分割，计算指标与差额；
- 结果导出：outputs/batch_results/<批次名>/
  - atch_metrics.csv / atch_metrics.xlsx：全部指标、差额、z 分数；
  - nnotated/：每张图片的分割叠加图；
  - atch_summary.json：批次汇总（处理数、异常数、指标均值等）；
  - nalysis_report.html：一键生成的分析报告（含图表与异常个体清单）；
- 异常筛查：|z| > 2 判为“明显偏离物种基线”，用于监测质控。

## 十一、启动方式

- 启动应用.bat：无控制台启动（推荐日常使用）；
- 启动界面.bat：调试模式，报错可见；
- 打包成exe.bat：使用 PyInstaller 打包为独立应用（data 目录需与 exe 同目录）。

## 八、说明

- 旧版“物种预测/分类器”代码已删除，本程序不进行任何预测；
- PCA 聚类图仅用于无监督展示特征分布，不作为预测依据；
- 特征矩阵与物种基线表位于 models_out/，统计图与 PCA 图位于 outputs/。
